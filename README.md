# Nucampsite React Project ⛺️
A React + Redux web app for browsing campsites and reading/leaving reviews. Built to practice real-world front-end patterns: component architecture, global state management, and async data handling.

Features


🔍 Browse Campsites — View a directory of campsites with details like location, description, and images
⭐ Reviews & Comments — Users can read existing reviews and submit their own comments/ratings on a campsite
🔐 Authentication — Login/auth flow to gate features like posting comments
📱 Responsive UI — Works across desktop and mobile screen sizes


Tech Stack


React — UI library, built with Create React App
Redux Toolkit — Global state management for campsites, comments, and auth
React Router — Client-side routing/navigation
JavaScript (ES6+)
CSS / HTML


What I Practiced


Structuring a multi-component React app with reusable presentational components
Managing global state with Redux Toolkit slices instead of prop drilling
Handling forms and user input for submitting reviews
Implementing protected routes/features behind authentication
